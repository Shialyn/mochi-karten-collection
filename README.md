# Mochi Karten Collection

Public artwork repository for Wooloo Cards Season 1.

Contains 48 active card illustrations in optimized WebP format: Common, Uncommon, Rare, Super Rare and Ultra Rare. Rank Rare artwork is reserved separately and is not included in the active set.

The private Wooloo bot references these images via GitHub Raw URLs. Filenames should remain stable because they are used as card IDs/image filenames.
